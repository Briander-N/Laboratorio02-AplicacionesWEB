## Descripción

Este proyecto consiste en el desarrollo de una página web que consume información de una API REST para obtener y mostrar los datos de un usuario. El objetivo es practicar el consumo de servicios web y la manipulación de información mediante JavaScript.

## API utilizada

Se utiliza la API de JSONPlaceholder para obtener los datos de un usuario.

- **Servicio:** JSONPlaceholder
- **Endpoint:** https://jsonplaceholder.typicode.com/users/1
- **Método HTTP:** GET

La respuesta de la API contiene información como el nombre del usuario, nombre de usuario, correo electrónico, dirección y otros datos.

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- API REST (JSONPlaceholder)

## Ejecución del proyecto

1. Clonar o descargar este repositorio.
2. Abrir la carpeta del proyecto.
3. Ejecutar el archivo `index.html` en un navegador web.
4. Verificar que la página cargue y muestre los datos obtenidos de la API.
